# homework-scan デモのブラウザ検証

## 対象と開き方
- `dist/demo.html` を `google-chrome "file:///home/ubuntu/repos/homework-scan/dist/demo.html"` で開くだけで動く。データは localStorage のモックで永続化される。
- **開始画面・暗証番号・全画面・Guard は全撤去済み**（PR #4〜5）。ページを開くと直接きょうの表が出る。先生画面は右上「先生の画面」ボタンで **PINなし**で直入りし、「係の画面へ」で戻る。
- **ロール分岐（BOOT.role は location.hash だけで決まる）**：`demo.html` 無印=staff（先生ボタンあり）、`#helper`=係児童（先生ボタンなし）、`#teacher`=先生画面から直開き。
- **罠：ハッシュだけを変えるURL遷移ではリロードされずロールが再評価されない**。`demo.html`→アドレスバーで`#helper`を足すだけでは staff のまま。ロールを試すときは **URLを入れた後に Ctrl+R で強制リロード** する。
- localStorage を消して再シードしたいとき：`browser_console` が "Chrome is not in the foreground" で使えない場合がある。回避策＝`localStorage.clear();location.replace("file://…/dist/demo.html")` を書いた /tmp の HTML を作ってアドレスバーで開く（file:// 同士で storage 共有）。
- 生成物は `python3 build.py` で作る。`python3 build.py --check` で src と一致確認。修正前版との比較は `git show <旧コミット>:dist/demo.html > /tmp/demo-old.html` で取り出す — file:// の localStorage は共有されるので同じシードデータで比較できる。

## 必須セットアップ（VMに無ければ先に）
- `sudo apt-get install -y fonts-noto-cjk && fc-cache -f` — **日本語フォントが無いと全UIが豆腐（□□□）になり視覚検証が不可能**。導入後は Chrome の全プロセスを kill して再起動（`pkill -9 -f google-chrome`、自分のシェルコマンドに chrome を含めると自爆するので注意）。
- `sudo apt-get install -y xclip` — **日本語の入力**。`type` アクション（xdotool）は日本語を打てない。`echo -n "文字列" | xclip -selection clipboard` でクリップボードに入れ、対象入力欄をクリック→`ctrl+v` で貼り付ける。
- 表示は 1600x1200・Chrome は `wmctrl -r :ACTIVE: -b add,maximized_vert,maximized_horz` で最大化。

## 画面の構造（src/js）
- 係の画面（helper.js）：左ペイン 1〜18番・右 19番〜（`SPLIT=18`）。マスはタップで `空白→○→休→忘→△→空白`（`Domain.NEXT`）。免除マスは○表示でタップ無効。
- 先生画面（teacher.js）：タブ＝きょうの表／分析／免除／名簿と品目／せってい。分析は「みんなの まとめ」区（提出率・提出時刻の平均/中央値、忘れた回数の合計/1人平均/最大(番号)、内わけ合計）＋気になる子＋児童ごと表。児童ごと表の「忘」列は `回数/出す数`（忘0なら `0` のみ）、末尾に `計・全員` の tfoot 合計行あり。
- **date 入力欄**：`type` は **クリックしたセグメントから8桁数字をそのまま打つ**（"09222026"→09/22/2026）が一番確実。「MM/DD/YYYY」形式も入るが、ctrl+a で全選択してから打つと年セグメントに数字が連結して化ける（"222026"等）ので避ける。
- 係管理表（名簿と品目の最下部）：「1人 たす」は押すたびにタブ全体が再描画されボタン位置がずれる → 連続追加は1回ずつ。空いつまで→学期末（12/31）、学期末超え→切詰、非メアド→保存で破棄。
- その日の品目：「きょうの表」のスロットチェックボックス＋名前入力欄で直接追加・改名できる（最大9枠）。今日の分は初回アクセス時に「いつも出す」から自動生成される。
- 名簿の氏名列：品目が増えると「あお…」程度に省略される（列幅の仕様、不具合ではない）。多品目運用は「せってい→氏名を出さない」想定。
- ウィンドウサイズを変えた検証は `wmctrl -r :ACTIVE: -e 0,x,y,w,h`（行高がclamp最小値を下回る極小窓では氏名が行をまたいで見えることがある）。
- 削除済みファイルでも **開いたままのタブには中身が残る** — 検証は新規タブで開き直すこと。

- 気になる子：7きむら(52%)・23のむら(58%・8日)・29みやざき(61%・4日)。
