# homework-scan（宿題チェック）

係の子が 自分のアカウントで開いて **マスをタップして** 毎日の宿題の提出を記録するアプリです。
記録は Google スプレッドシートにたまり、先生は教職員のアカウントで履歴・免除・分析を見ます。

- 係の子が見られるのは **その日の表だけ**（左に 1〜18 番、右に 19 番から）
- 先生の画面（品目・欠席・免除・名簿・分析・せってい）は教職員のアカウントでしか開けない（暗証番号は使わない）
- Google Apps Script（GAS）のウェブアプリ。サーバや追加の機器は要らない

## マスの切り替わり

タップするたびに、次の順で変わります。

| 表示 | 意味 | 記録（提出記録シートの「操作」） | 集計 |
|---|---|---|---|
| （空白） | まだ | 空白 | 未提出 |
| ○（青） | 出した | 提出 | **提出** |
| 休（灰） | 休み | 休み | **提出** |
| 忘（黄） | 家に忘れた | 忘れた | 未提出 |
| △（黒わく） | 今やっている | やっている | 未提出 |

空白 → ○ → 休 → 忘 → △ → 空白 と一周します。

- 記録は **追記だけ** です。空白に戻したときも「空白」の行が増えるので、履歴は消えません。
- 送るのは「押した回数」ではなく「変えたあとの状態」です。通信の再送や、2台で同時に押しても、状態がとびません。
- 通信が切れても PC の中に一時保存し、つながったら送ります（右上の雲のアイコンで分かります）。
- 色だけで区別しないよう、状態は必ず記号か文字と一緒に出します。

### 欠席と免除

- **欠席**：先生が「きょうの表」で欠席にした子は、全部のマスが「休」で出て、提出として数えます。係が押し直せば、そちらが優先です。
- **免除**：期間・品目を決めて免除できます。免除のマスは提出の数に入れません。係の画面では ○ と同じ見た目で、押しても変わりません。理由のメモは先生の画面にだけ出ます。

### 分析（先生の画面）

- 提出率 ＝（○＋休）÷（出す数 − 免除 − 欠席の日）
  - 先生が「欠席」にした日は分母に入れません（欠席が多い子の率が高く見えないように）。係が「休」を付けたマスは分母に入れ、提出として数えます。
- 数える日は、その日に最初の印が付いたとき、または先生がその日の品目を決めたときに決まります。画面を開いただけの日（土日・休日を含む）は数えません。
- 平均・中央値の提出時刻は、**係がタップした ○ の時刻だけ** から出します（先生が後から直した印は時刻に入れません）。
- 提出率が目安（初期値 80%）を下回る子、目安（初期値 3日）以上続けて未提出の子に印が付きます。

## 使い方（毎日）

1. 係の子が自分のアカウントでアプリの URL を開く
2. マスをタップしていく
3. 先生は同じ URL を教職員のアカウントで開くと、右上の「先生の画面」から直しや分析ができる

その日の提出物（品目）は、先生の画面「きょうの表」で決めます。「名簿と品目」で「いつも出す」にした品目は、何もしなければ毎日並びます（初期値：漢字ドリル・計算ドリル・連絡帳）。
品目ごとに列の色を決められます（初期値：漢字ドリル＝薄赤・計算ドリル＝薄青・連絡帳＝薄緑）。色は「名簿と品目」で変えられます。

### 時刻のずれ

端末は、送るときに自分の時計の時刻もいっしょに送ります。サーバの時計との差で各記録の時刻を直すので、Chromebook の時計がずれていても、2台で押した印の前後は入れかわりません。

## はじめての設定（先生）

1. 新しい Google スプレッドシートを作り、「拡張機能 → Apps Script」を開く
2. `gas/` の中のファイルを、同じ名前で Apps Script に入れる
   - `Api.gs` `Domain.gs` `Gate.gs` `Platform.gs`（スクリプト）
   - `Index.html`（HTML）
   - `appsscript.json`（「プロジェクトの設定 → マニフェストを表示」にしてから中身を入れ替える）
3. エディタで関数 `setupSheets` を1回実行する（表が作られる）
4. 「デプロイ → 新しいデプロイ → ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**（学校のドメイン）内の全員**
   - 係の児童に自分のアドレスで開かせるには、児童のアドレスが**同じ Workspace 組織の中**にある必要があります（組織外の Google アカウントだと、開いた人のアドレスをアプリが読めず入れません）。
5. 表示された URL を開き、先生の画面「名簿と品目」で係の児童のアドレスを入れる
6. 「名簿と品目」で名簿を貼りつけて保存する（Excel やスプレッドシートから「番号・氏名」の2列をコピー）
7. 係の子に URL を渡す（Classroom の資料やブックマークなど）

### 入れる人

| アカウント | 係の画面 | 先生の画面 |
|---|---|---|
| 教職員（`@edu.nishi.or.jp`） | ○ | ○ |
| 「係」に入れた児童（期限内） | ○（きょうの分だけ） | × |
| そのほかの児童・学校外 | × | × |

- 係の児童は、先生の画面「名簿と品目」の「係の画面を 開ける児童」にアドレスを入れます。
- 期限は**学期末（3月末・8月末・12月末の直近）まで**です。もっと早く切りたいときだけ日付を入れます。学期を越えると自動で開けなくなり、新学期は保存し直します。
- 暗証番号は使いません。サーバの口（名簿・免除・分析など）もアカウントで確かめるので、画面を回り込んでも児童は先生の口を呼べません。
- スプレッドシートは児童に共有しないでください。Web アプリは持ち主の権限で動くので、共有しなくても記録できます。

### スプレッドシートの表

| シート | 中身 |
|---|---|
| 名簿 | 番号・氏名 |
| 品目 | 枠・名前・アイコン・いつも出すか・列の色 |
| 日の品目 | 日ごとの提出物 |
| 提出記録 | 1タップ1行（日付・番号・品目・操作・時刻・入力・端末） |
| 欠席 | 日付・番号 |
| 免除 | 番号・品目・はじめ・おわり・メモ |
| 係 | 係の画面を開ける児童（アドレス・いつまで・メモ） |
| 操作記録 | だれが係の画面・先生の画面を開いたか |
| 設定 | 提出率の目安など |

シートを手で直すこともできますが、提出記録は消さずに行を足す形で直してください。

## 開発

```
src/            画面（HTML・CSS・JS）
gas/            Apps Script に入れるもの（Index.html は生成物）
dist/demo.html  Google なしで動くデモ（データは PC の中だけ）
tests/          サーバ側のテスト（node）
```

```
python3 build.py          # gas/Index.html・dist/ を作る
python3 build.py --check  # 生成物が src と一致しているか
node tests/server.test.js # サーバ側の決まり
```

生成物は直接直さず、`src/` を直してから `build.py` を実行してください。
デモは `dist/demo.html` をブラウザで開くだけで動きます（`#teacher` で先生の画面から、`#helper` で係の児童として）。
